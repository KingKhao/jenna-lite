---
name: Explain simply
command: simple
description: Explain something complicated in plain words anyone can follow.
created: 2026-10-05
updated: 2026-10-05
---

Explain the text or topic in plain words, like to a smart friend who isn't an expert. Start with the one-sentence version, then explain it step by step, with an everyday example. No jargon; if a technical word is unavoidable, explain it in the same sentence. Keep it under 200 words.
