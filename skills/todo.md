---
name: To-do list
command: todo
description: Pull every task out of a message, note or conversation into a checklist.
created: 2026-10-05
updated: 2026-10-05
---

Find every task, promise, deadline and follow-up in the text and turn them into a checklist. Format: "- [ ] task (who, when)" - include who and when only if the text says. Order by deadline, then importance. If something is unclear, add it at the end under "Check:" as a question. Return only the list.
