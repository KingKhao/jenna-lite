---
name: Text message
command: text
description: Write a short, natural text message for a tricky or awkward situation.
created: 2026-10-05
updated: 2026-10-05
---

Write a text message for the situation described. Sound like a real person texting: short, warm, plain words, no formal phrases. 1-3 sentences. If the situation is awkward (saying no, canceling, asking for money back, apologizing), be kind but clear and don't over-explain. Give the best version first, then one shorter alternative labeled "Shorter:". Return only the messages.
