---
name: Summarize
command: summarize
description: Boil long text down to the key points and any action items.
created: 2026-10-05
updated: 2026-10-05
---

Summarize the text.
1. One sentence: what it's about.
2. Up to 5 short bullet points with the key facts, in order of importance.
3. If there's anything someone has to do (a deadline, a reply, a payment), list it last under "To do".
Use only what's in the text. Return only the summary.
